# Гелиус Синерджи

Интерактивный дашборд экосистемы ИИ-агентов Корпорации «Синергия».

**Сайт: https://stepansky0012.github.io/helius-synergy/**

Данные — стратегия проекта «ИИ-агенты в Корпорации «Синергия»» от 03.09.2026.

---

## Как читается карта

Полярная матрица с двумя независимыми осями. Ни один канал не дублирует другой.

| Канал | Что кодирует |
|---|---|
| **Радиус** | стадия зрелости: Реестр → Прототип → Пилот L1 → Промышленная L2 → Автономная L3 |
| **Сектор** | продуктовая линейка; ширина сектора пропорциональна числу агентов в нём |
| **Форма мона** | линейка (тот же ключ, что у сектора) |
| **Обод** | пунктирный, если в стратегии не описаны проблема, действие и эффект |
| **Красный** | открытый долг или блокер; единственное красное на карте |

Матрица вращается как одно жёсткое целое — оборот за 220 секунд. Угол кодирует
линейку, поэтому агент не вправе уезжать из своего сектора: секторы, спицы и
подписи поворачиваются тем же углом. Наведение курсора останавливает вращение.

Клик по агенту открывает **анатомию** — радиальную схему из шести слотов,
одинаковых для всех агентов: роль, эффект, линейка, стадия, ответственный,
системы. Второй режим страницы — целевые показатели до 2028 года, воронка
внедрения из семи этапов и ограничения.

На телефоне борта становятся полосами чипов, вращение выключается (пальцем в
движущуюся цель не попасть), а выноски анатомии заменяются списком.

## Состав

| Файл | Назначение |
|---|---|
| `index.html` | вся страница: разметка, стили, логика, данные. Без сборки и серверной части |
| `Гелиус_агенты.xlsx` | источник данных об агентах — то, что правится руками |
| `sync.py` | переносит таблицу в страницу, проверяет её и публикует |
| `sync.cmd` | запуск `sync.py --deploy` под Windows |

Единственная внешняя зависимость страницы — шрифты с `fonts.googleapis.com`
(Unbounded, Golos Text, JetBrains Mono). Всё остальное внутри файла.

## Как менять состав агентов

Агенты живут в `Гелиус_агенты.xlsx`, а не в коде. Блок `var A = [...]` внутри
`index.html` генерируется из таблицы и помечен маркерами
`АГЕНТЫ · НАЧАЛО` / `АГЕНТЫ · КОНЕЦ` — править его руками бессмысленно,
правки затрутся при следующей синхронизации.

1. Открыть `Гелиус_агенты.xlsx`, лист **«Агенты»**.
2. Столбцы `D–J` — свободный текст. `Категория` и `Стадия` — только значения
   из выпадающего списка (лист **«Справочник»**). Столбец `id` — ключ
   сопоставления строк, менять его не нужно.
3. **Добавили строку — на карте появится агент. Удалили строку — исчезнет.**
   Новой строке нужен новый короткий `id` латиницей.
4. Запустить `sync.cmd`.

Сухая проверка без записи:

```
python sync.py --check
```

Перенести правки, но не публиковать:

```
python sync.py
```

Перенести и опубликовать:

```
python sync.py --deploy
```

Синхронизация отказывается работать при дублирующемся или неправильном `id`,
неизвестной категории или стадии, пустом названии — с указанием номера строки.
При отказе ни страница, ни сайт не меняются.

Требуется `python` с `openpyxl` и `node` в `PATH`. Категории и стадии скрипт
читает из самой страницы, поэтому переименование категории синхронизацию
не ломает.

### Локальная раскладка

`sync.py --deploy` ожидает, что рядом с рабочей папкой лежит клон этого
репозитория:

```
...\helius-synergy\      рабочая папка: index.html, таблица, скрипты
...\helius-pages\        клон этого репозитория, из него публикуется сайт
```

В свежем клоне второй папки нет, и `--deploy` честно об этом скажет. Для
своей раскладки поправьте путь в `deploy()`.
