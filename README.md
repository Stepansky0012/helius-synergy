# Гелиус Синерджи

Интерактивный дашборд экосистемы ИИ-агентов Корпорации «Синергия».

Полярная матрица: радиус — стадия зрелости агента, сектор — продуктовая линейка.
У каждого агента один и тот же набор из шести полей; клик открывает анатомию.
Второй режим — целевые показатели, воронка внедрения и ограничения.

Одна самодостаточная страница: `index.html`, без сборки и серверной части.
